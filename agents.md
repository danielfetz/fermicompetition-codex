Create a Duolingo-style web app for the "Fermi competition" that uses Supabase (to create tables there provide SQL for me to copy).

Font-family used should be Nunito. 

There should be a teacher log-in/sign-up.

Afterwards they can register their classes to the competition and add how many students are participating in each class. For every student a username and password is generated. Teachers can also manually add a full name to every student. But this should by default be what students enter when they first log in using their credentials.

Then afterwards they can add/override the answers each of the students gave to each of the 10 Fermi questions (there is always a answer field and a percentage dropdown where one can select between 10, 30, 50, 70, 90% which are the options the students had)

If users choose to play using the Fermi questions student app which just shows the 10 questions, has a 40minute time limit and gives the option to add an answer and confidence percentage this should fill the data in the table the teachers sees directly

Then it should automatically compare how many of the questions the student got correct (it counts when it falls under +/- 50% of the correct answer).

The Fermi questions should not be provided by the teacher, but by the system per default since this competition takes place at many different schools and classes.
